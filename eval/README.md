# Phase 1 黄金评测集

`gold_prompts.jsonl` 是首版公式推导与函数可视化的版本化评测资产。每行是一个独立 JSON 对象，必须通过：

```bash
python3 scripts/validate_gold_set.py
python3 -m unittest tests/test_validate_gold_set.py
```

## 数据组成

- 15 条 `formula_derivation`
- 15 条 `function_visualization`
- 每条必须标注来源是模拟访谈还是匿名真实访谈
- 项目发起人已批准模拟访谈满足 Phase 1 内部开发门禁，但不代表真实市场验证
- 所有进入黄金集的条目必须由父 agent 复核并标记 `parent_validated`

## 统一人工评分

每项使用 1–5 分：

| 维度 | 权重 | 5 分标准 | 1 分标准 |
|---|---:|---|---|
| 数学正确性 | 40% | 公式、定义域、关键点、推导和结论全部正确 | 存在影响结论的数学错误 |
| 视觉清晰度 | 25% | 关键对象易辨认，无明显遮挡或越界 | 关键内容不可读或无法跟随 |
| 教学解释性 | 20% | 场景顺序支持目标受众理解概念 | 只是展示结果，没有解释过程 |
| 规划一致性 | 15% | 完整覆盖 must_include，未触发 must_avoid | 遗漏关键要求或违背禁止项 |

综合分为加权平均。数学正确性低于 4 分时，无论综合分多少都判定失败。

## 条目审查规则

1. 原始 Prompt 保留自然表达，不改写成内部技术指令。
2. `must_include` 描述可观察的公式、对象或步骤。
3. `must_avoid` 描述会使动画不可用的具体错误。
4. `correctness_checks` 必须能由人工或后续自动规则验证。
5. 时间范围满足 `30 <= min <= target <= max <= 180`。
6. 重复教学目标只保留更真实、约束更清楚的一条。
7. 涉及几何证明、线性代数、语音、用户素材或任意代码编辑的需求标记为首版范围外，不进入这 30 条核心集。
