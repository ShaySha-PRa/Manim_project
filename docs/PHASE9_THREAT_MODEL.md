# Phase 9 STRIDE 威胁模型

日期：2026-08-05

| 边界 | 风险 | 失败关闭控制 | 验证 |
|---|---|---|---|
| MP4/图像解析 | 畸形媒体、资源耗尽 | 大小/帧数/时长上限、超时、只读输入、沙箱解析 | 畸形语料与超时注入 |

| 质量报告 | 篡改历史、伪造通过 | append-only、数据库约束、策略版本和签名 | UPDATE/DELETE 失败测试 |
| 自动修复 | 无限循环、提示注入 | 两次预算、类别模板、重复签名熔断、Phase 7 全边界重验 | 重复性与注入测试 |
| 评分 | 阈值规避、静止凑时长 | 严重项 veto、静止比例门禁、实际帧级核验 | 失败注入黄金集 |

| API | IDOR、存在性泄漏 | Session owner 推导、统一 404、参数化 SQL | 跨用户 API/SSE/Artifact 集 |
| 日志 | 密钥、Prompt、源码泄漏 | allowlist 字段、摘要代替原文、脱敏扫描 | secret corpus |

## 安全不变量

1. 诊断器不执行候选 Python，不调用外部网络，不跟随 Artifact 根目录外路径。
2. 报告和证据先按 owner 查询；UUID 不是授权。
3. 质量通过不能覆盖 Phase 5 沙箱或 Phase 7 安全失败。
4. 修复后的每个候选重新经过 AST、编译、Scene、沙箱与质量全链路。
5. 两次修复、重复诊断签名或预算耗尽后必须终止。
6. 报告不得包含 Prompt、完整源码、Session/CSRF、密钥或宿主绝对路径。
