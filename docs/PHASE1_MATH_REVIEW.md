# Phase 1 数学正确性复核

## 复核方法

父 agent 对 30 条入选任务逐条检查公式结论、成立条件、定义域、关键点、导数或积分关系，并将可观察断言写入 `correctness_checks`。结构校验器确保每条任务同时具有必须内容、禁止错误、预期场景和有序时长范围。

## 重点复核项

- 推导类：等式变形保持等价，链式法则和乘积法则因子完整，换元与分部积分步骤方向正确。
- 极限与微积分：明确极限过程、积分上下限和微积分基本定理中的变量关系。
- 函数类：定义域、截距、极值、凹凸区间、切线斜率和面积符号正确。
- 参数动画：参数变化只改变对应几何性质，不误导为错误的平移、伸缩或周期关系。
- 分段与复合函数：端点取值、连续/可导区别和根式定义域必须显式呈现。

## 判定规则

数学正确性按 1–5 分评分，低于 4 分即使总分达标也判定失败。当前复核证明黄金任务及其验收断言自洽，不等于证明未来模型输出一定正确；模型输出仍须逐条执行这些断言和人工抽查。
